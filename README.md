## 📄 Sobre o Projeto

O **Atlantis III** é um sistema de gerenciamento para o parque aquático e resort desenvolvido inteiramente em **TypeScript**. Esta versão opera via **Linha de Comando (CLI)**, focando na estruturação das classes, manipulação de dados e lógica de negócios antes da implementação da interface gráfica.

O objetivo principal é garantir a consistência dos dados e o funcionamento correto das operações de gerenciamento do hotel.

## ⚙️ Funcionalidades

O sistema permite a execução de operações fundamentais através do terminal:

* **Gestão de Clientes:** Cadastro, leitura, atualização e exclusão (CRUD).
* **Controle de Acomodações:** Gerenciamento dos quartos e áreas do resort.
* **Sistema de Reservas:** Lógica para realizar hospedagens.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Ambiente de Execução:** Node.js
* **Transpilação:** TSC (TypeScript Compiler)

## 📦 Como Executar o Projeto

Como o projeto foi desenvolvido em TypeScript, é necessário realizar a instalação das dependências e a transpilação do código para JavaScript antes da execução.

### 1. Instalação
No terminal, dentro da pasta raiz do projeto, execute:

```bash
npm install
```
## 2. Compilação (Build)
Converta os arquivos TypeScript para JavaScript utilizando o compilador:

```bash
tsc
```

## 3. Execução
Após a compilação, inicie o sistema executando o arquivo principal gerado:

```bash
node src/js/app/app.js
```
