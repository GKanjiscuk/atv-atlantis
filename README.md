## 📄 Sobre o Projeto

O **Atlantis IV** representa a evolução do sistema de gerenciamento do parque aquático e resort. Anteriormente operando via linha de comando (CLI), o sistema foi migrado para uma **Single Page Application (SPA)**.

Esta mudança atende à necessidade de modernização apontada pelos relatórios de marketing, visando oferecer uma interface amigável, intuitiva e compatível com os padrões modernos de **Usabilidade e IHC**, facilitando a operação por parte dos funcionários e gestores.

## 🎯 Funcionalidades Implementadas

Conforme os requisitos da atividade, o protótipo navegável contempla:

* **👥 Gestão de Clientes (Hóspedes):**
    * Cadastro, listagem, atualização e remoção de clientes (CRUD).
* **imóveis Gestão de Acomodações:**
    * Cadastro e visualização dos quartos e áreas disponíveis no resort.
* **📅 Registro de Hospedagens:**
    * Sistema para realizar o check-in e controle de estadias.
